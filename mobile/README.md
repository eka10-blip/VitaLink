# Mobile Application

VitaLink patient + caregiver UI (Person 4), with **Person 2 iOS sensing** wired into Check-in.

- Person 4 demo/live UI: see `PERSON4_README.md`
- Person 2 iOS LiveKit + Presage: see `PERSON2_IOS.md`
- API contract: `INTEGRATION_CONTRACT.md`

Person 2 sensing requires an iOS **dev build** (`npx expo run:ios`) and `EXPO_PUBLIC_PRESAGE_WORKER_URL` pointing at `backend/presage-worker`.
